# luke进行曲同款视频

**上传你的人物照和穿搭图，自动把你做成这支 Luke 进行曲卡点视频里的主角。**

[![点击观看成片示例](assets/preview.jpg)](assets/reference-final-v5.mp4)

▶ [观看／下载成片示例](assets/reference-final-v5.mp4) · **v5 抬镜直视模特步版** · 10.5 秒 · 1080p 竖屏

1. 上传清晰的人物照和穿搭图，你自己的或别人的穿搭都可以；没有穿搭图也可提供描述。
2. Agent 会先解释 VidMuse 的生成、剪辑能力，并询问你是否愿意连接。你确认后，才引导安装与登录；由你自己复制执行，或明确授权 Agent 代为操作。
3. 连接成功后，自动建立人物三视图、穿搭三视图，再按你的制作确认生成完整卡点视频。已经连接并授权的用户可直接继续。

VidMuse CLI 是 Agent 调用这些能力的接口；安装命令并不等于登录授权。连接制作会上传本次素材到你的 VidMuse 工程，并使用你的生成额度。

开头从人物已戴好墨镜开始，再扶镜、看向镜头，接踩鼓点的大步模特步；先核验戴镜首帧，避免墨镜凭空出现。上方v5视频用于展示气场与剪辑，后续生成按此起始状态要求执行。

12 个固定场景保留，主角和穿搭换成你。制作在同一个完整 VidMuse thread 中完成，之后也能继续修改。

## 使用

把本文件夹放进 `~/.codex/skills/`，在 Codex 中说：

> 用「luke进行曲同款视频」帮我做同款，这是我的照片。

也可用 `$luke-march-video` 调用。需要可用并已登录的 VidMuse；制作会使用你账号的生成额度。参考音乐、图片、动作和时间线都已内置，不必另外找素材。
